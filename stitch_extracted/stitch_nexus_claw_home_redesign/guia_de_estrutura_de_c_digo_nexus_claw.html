# Estrutura de Arquivos Recomendada (Next.js + Tailwind) Para organizar o código que você exporta do Stitch no seu repositório `kashikai/nexusclaw`, siga esta estrutura profissional: ## 1. Componentes Globais (`/components/layout`) Copie as partes repetitivas (Navbar, Sidebar, Footer) para arquivos separados: - `Navbar.tsx`: O código do menu superior. - `Sidebar.tsx`: O menu lateral do terminal. - `Footer.tsx`: O rodapé com links de auditoria. ## 2. Páginas Principais (`/pages` ou `/app`) Cada tela principal do Stitch deve ser um arquivo: - `index.tsx`: Home / Redesign Principal ({{DATA:SCREEN:SCREEN_10}}). - `staking.tsx`: Terminal de Staking ({{DATA:SCREEN:SCREEN_17}}). - `governance.tsx`: Portal de Governança ({{DATA:SCREEN:SCREEN_15}}). - `analytics.tsx`: Analytics Profundo ({{DATA:SCREEN:SCREEN_4}}). ## 3. Modais e Overlays (`/components/modals`) Estes são componentes que aparecem "por cima" da tela: - `ConnectWalletModal.tsx`: O Modal de Conexão ({{DATA:SCREEN:SCREEN_12}}). - `ConfirmStakeOverlay.tsx`: O Overlay de Confirmação ({{DATA:SCREEN:SCREEN_14}}). ## 4. Integração Web3 (A Mágica) No seu arquivo `_app.tsx` ou `layout.tsx`: 1. Configure o **WagmiProvider** e o **RainbowKitProvider**. 2. No botão "Connect Wallet", use o componente `` do RainbowKit. 3. Para os dados reais (ex: Saldo), use: ```javascript const { data: balance } = useBalance({ address: userAddress }); ``` **Dica:** Sempre que você atualizar o design aqui, basta copiar o novo HTML e substituir o conteúdo dentro da `div` principal da sua página no VS Code.
